# Carousel Studio

โปรแกรมเขียนและออกแบบคอนเทนต์ Carousel สำหรับโพสต์และแอด Facebook ใช้ได้กับ Claude, ChatGPT และ Gemini

## ติดตั้งบนเครื่อง (Windows)

1. ดับเบิลคลิก `Install.bat`
2. จะได้ไอคอน **Carousel Studio** บนหน้าจอ Desktop และในเมนู Start
3. คลิกไอคอนแล้วโปรแกรมจะเปิดเป็นหน้าต่างแอปของตัวเอง ไม่มีแถบที่อยู่เว็บ (ใช้ Microsoft Edge หรือ Google Chrome ที่มีในเครื่อง)
4. ถอนการติดตั้งด้วย `Uninstall.bat` ซึ่งจะลบแค่ไอคอนทั้งสองจุด ไฟล์ในโฟลเดอร์นี้ยังอยู่ครบ

ข้อควรรู้
- ห้ามย้ายหรือเปลี่ยนชื่อโฟลเดอร์นี้หลังติดตั้ง ถ้าย้ายแล้วให้กด `Install.bat` อีกครั้ง
- ต้องต่ออินเทอร์เน็ต เพราะโปรแกรมโหลดฟอนต์ไทย ตัวสร้างไฟล์ zip และเรียก AI ผ่านอินเทอร์เน็ต
- เครื่องอื่นติดตั้งได้โดยคัดลอกทั้งโฟลเดอร์ `Carousel Studio` ไปไว้ในเครื่องนั้น แล้วกด `Install.bat`
- ถ้ายังไม่อยากติดตั้ง ดับเบิลคลิก `Carousel-Studio.html` เพื่อเปิดในเบราว์เซอร์ได้เหมือนกัน

## ใช้เป็นเว็บแอป (ไม่บังคับ, โฟลเดอร์ `webapp`)

โฟลเดอร์ `webapp` คือเวอร์ชันเว็บแอปที่ติดตั้งลงเครื่องหรือมือถือได้ และเปิดใช้แบบออฟไลน์ได้หลังเปิดครั้งแรก (ยกเว้นการเรียก AI) ต้องนำขึ้นเว็บโฮสติ้งก่อน เพราะการเปิดจากไฟล์ในเครื่องโดยตรงจะติดตั้งเป็นแอปไม่ได้

1. อัปโหลดทั้งโฟลเดอร์ `webapp` ขึ้นโฮสติ้งแบบเว็บไฟล์นิ่งที่เป็น https เช่น GitHub Pages, Netlify หรือ Cloudflare Pages
2. เปิดลิงก์ที่ได้ใน Chrome หรือ Edge แล้วกดปุ่ม **ติดตั้งแอป** ที่มุมขวาบน (หรือไอคอนติดตั้งในแถบที่อยู่)
3. บน iPhone ให้เปิดใน Safari แล้วกด **แชร์ → เพิ่มไปยังหน้าจอโฮม**
4. ถ้าแก้โปรแกรมเวอร์ชันใหม่ ให้อัปโหลดไฟล์ทับของเดิม ผู้ใช้จะได้เวอร์ชันใหม่ตอนเปิดแอปขณะต่ออินเทอร์เน็ต

## เลือก AI ที่จะใช้ (กล่อง “การเชื่อมต่อ AI”)

| ตัวเลือก | ต้องมี | หมายเหตุ |
|---|---|---|
| คัดลอกไปวางใน AI ตัวไหนก็ได้ | บัญชี ChatGPT, Gemini หรือ Claude แบบปกติ (ฟรีก็ได้) | โปรแกรมสร้างคำสั่งให้คัดลอกไปวางในหน้าแชท แล้วคัดลอกคำตอบกลับมาวาง |
| Claude API | API key จาก platform.claude.com | คิดเงินตามการใช้งาน |
| ChatGPT API | API key จาก platform.openai.com | คิดเงินตามการใช้งาน |
| Gemini API | API key จาก aistudio.google.com | มีโควตาฟรี |

- ชื่อโมเดลแก้ได้ในช่อง “โมเดล” ถ้าผู้ให้บริการออกรุ่นใหม่ ให้พิมพ์ชื่อรุ่นใหม่ลงไปได้เลย
- คีย์จะถูกส่งจากเบราว์เซอร์ไปยังผู้ให้บริการ AI โดยตรงเท่านั้น ถ้าติ๊ก “จำคีย์ไว้ในเครื่องนี้” คีย์จะเก็บในเบราว์เซอร์ของเครื่องนั้น
- อย่าติ๊กจำคีย์บนเครื่องที่ใช้ร่วมกับคนอื่น และอย่าส่งต่อไฟล์ที่มีคีย์ (ตัวไฟล์โปรแกรมไม่มีคีย์ติดไปด้วย)

## ออกแบบตามธีมของเพจ

1. ในกล่อง “ธีม” กด **เพิ่มภาพของเพจ** แล้วเลือกโลโก้ ภาพปก หรือภาพหน้าจอโพสต์เดิม ได้สูงสุด 4 ภาพ
2. ถ้ารู้รหัสสีแบรนด์ ให้พิมพ์ลงในช่องสีแบรนด์ เช่น `#0E8C8C, #F2B705`
3. กด **สร้างธีมจากสีของเพจ** จะได้ 3 ธีม (สว่าง / เข้ม / สีแบรนด์) โดยดึงสีจากภาพในเครื่อง ไม่ต้องใช้ AI
4. หรือกด **ให้ AI วิเคราะห์สไตล์เพจ** ให้ AI ดูภาพแล้วเลือกสี ฟอนต์ และเลย์เอาต์ พร้อมสรุปน้ำเสียงการเขียนของเพจ
5. วางแคปชันเก่า 2–3 โพสต์ในช่อง “ตัวอย่างโพสต์เดิมของเพจ” เพื่อให้ AI เขียนด้วยสำนวนเดียวกับเพจ

## ขั้นตอนทำคอนเทนต์

1. กรอกบรีฟ แล้วกด **สร้างคอนเทนต์ด้วย AI**
2. แก้ข้อความในแต่ละสไลด์ได้เอง ถ้าครอบคำด้วย `*ดอกจัน*` คำนั้นจะเป็นสีเน้น
3. ใส่รูปประกอบในสไลด์ได้ หรือกด “AI เขียนใหม่” ทีละใบ หรือพิมพ์สั่งให้ AI ปรับทั้งชุด
4. กด **ดาวน์โหลดภาพทั้งหมด (.zip)** จะได้ภาพ PNG ขนาด 1080 px ทุกสไลด์ และไฟล์ `copy.txt` ที่มีแคปชันกับข้อความแอด
5. นำภาพและข้อความไปตั้งค่าใน Meta Ads Manager หรือโพสต์บนเพจ

## ข้อจำกัด

- โปรแกรมไม่ได้เชื่อมกับบัญชี Facebook จึงโพสต์หรือยิงแอดให้อัตโนมัติไม่ได้
- งานร่าง ธีม และโลโก้เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ส่วนรูปที่ใส่ในสไลด์และภาพของเพจต้องใส่ใหม่ทุกครั้งที่เปิด
- ตัวเลือก “Claude ในหน้านี้” ใช้ได้เฉพาะตอนเปิดผ่านลิงก์ใน Claude เท่านั้น
